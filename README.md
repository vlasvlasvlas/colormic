# ColorMic

Instrumento web para performance audiovisual con microfono: color reactivo, presets YAML y procesamiento de sonido con reverb, delay, filtro, compresor y LFO.

## Local

```bash
python3 -m http.server 5174
```

Abrir `http://localhost:5174/`.

## GitHub Pages

El sitio es estatico (`HTML + CSS + JS`) y se despliega con GitHub Actions desde `.github/workflows/pages.yml`.
